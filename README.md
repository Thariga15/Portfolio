## 🚀 Quick Setup & Local Preview

1. **Open Directly in Browser**:
   - Double-click `index.html` or open it with your web browser (Chrome, Edge, Firefox, Safari).

2. **VS Code Live Server (Recommended)**:
   - If using VS Code, install the **Live Server** extension.
   - Right-click `index.html` and click **"Open with Live Server"**.

## 🌐 Deploy to GitHub Pages (Free Hosting)

1. Push this project folder to a repository on GitHub (e.g. `Thariga15/portfolio` or `Thariga15/Thariga15.github.io`).
2. In your GitHub repository, go to **Settings** > **Pages**.
3. Under **Branch**, select `main` (or `master`) and `/root`, then click **Save**.
4. Your site will be live at `https://thariga15.github.io/portfolio/` in a couple of minutes!
